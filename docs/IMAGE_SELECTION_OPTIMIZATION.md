# 图片选择优化说明

## 问题背景

在优化了评分细则后，发现图片选择逻辑不够准确，导致：
- 选择的图片与评分项不匹配
- 发送给AI模型的图片无法提供有效的评分信息
- 例如："应急疏散可操作性"评分项选择了空白页或文档页面，而不是实际的疏散路线图

## 优化方案

创建了**智能图片选择器** (`SmartImageSelector`)，根据每个评分项的具体要求精准选择最相关的图片。

## 核心改进

### 1. 专门的选择策略

为每个评分项类型创建了专门的选择方法：

#### **应急疏散路线图选择** (`_select_evacuation_route_images`)
- ✅ 高优先级关键词：疏散、逃生、集合点、集结点、应急
- ✅ 路线相关：路线、路径、通道、方向、箭头、标注
- ✅ 集合点相关：集合点、集结点、疏散点、安全区、位置
- ✅ 影响半径：影响半径、半径
- ✅ 视觉特征：地图类图片优先（+500分），有路线标记（+300分），有文字标注（+200分）
- ✅ 排除：空白页、纯文本页（-1000分）

#### **入场线路图选择** (`_select_entry_route_images`)
- ✅ 入场相关关键词：入场、进入、路线、路径、道路
- ✅ 标注相关：标注、说明
- ✅ 合理性检查：合理、可行、道路、桥、障碍
- ✅ 地图类图片优先

#### **影像图标注选择** (`_select_image_annotation_images`)
- ✅ 影像图关键词：影像图、影像、图像、卫星、航拍、示意图
- ✅ 管道位置：管道 + 位置/标注
- ✅ 影响半径：影响半径、潜在影响半径
- ✅ 线条：实线、虚线、线条
- ✅ 建筑物标注：建筑物、建筑、名称、人员数量、环境受体

#### **签字页选择** (`_select_signature_images`)
- ✅ 页码优先（前3页）
- ✅ OCR关键词：编制、审核、批准、校对、签字、签章
- ✅ 日期模式匹配
- ✅ 视觉特征：红色印章、表格线

### 2. 视觉特征检测

新增多个辅助方法，通过图像处理检测图片特征：

- **`_is_map_like_image()`**: 判断是否为地图类图片
  - 颜色多样性检测
  - 边缘密度检测
  - 文字标注区域检测

- **`_has_route_lines()`**: 检测图片中是否有路线线条
  - 使用Canny边缘检测
  - Hough直线检测
  - 判断是否有足够的路线标记

- **`_is_blank_or_text_only()`**: 排除空白页或纯文本页
  - OCR文本长度检查
  - 白色占比检测（>90%认为是空白页）

- **`_estimate_signature_visual_relevance()`**: 估算签字页相关性
  - 红色像素占比（印章）
  - 线条密度（表格）

### 3. 评分系统

每个图片根据以下维度评分：
1. **OCR文本关键词匹配**（150-300分/关键词）
2. **视觉特征匹配**（200-500分）
3. **页码位置**（50-1000分）
4. **特殊模式匹配**（日期、标注等，50-200分）
5. **排除惩罚**（空白页等，-1000分）

最终按分数排序，选择top N张图片。

## 使用方式

### 在评分引擎中自动使用

评分引擎已集成智能图片选择器，会自动根据评分项选择图片：

```python
# 在评分引擎初始化时
self.image_selector = SmartImageSelector()

# 在各个多模态评分方法中
images = self.image_selector.select_images_for_criterion(
    document, 
    criterion_key="evacuation_route_annotation",
    criterion_config=config,
    limit=3
)
```

### 评分项路由

评分引擎会自动识别评分项类型：

- `evacuation_route_annotation` → 应急疏散路线图选择
- `entry_route_annotation` → 入场线路图选择
- `image_annotation_recognition` → 影像图标注选择
- `signature_recognition` → 签字页选择
- 其他 → 基于关键词的通用选择

## 效果对比

### 优化前
```
选择图片数: 3/8
选中的图片:
  图片1: 文档页面（表格/文本）- 不相关 ❌
  图片2: 空白页面 - 不相关 ❌
  图片3: 地图视图 - 部分相关 ✓
  
评分结果: 10/15 (66.7%)
问题: 集合点和疏散通道在图片中没有清晰标注
```

### 优化后
```
选择图片数: 3/8
选中的图片:
  图片1: 应急疏散路线图（有标注）- 高度相关 ✅
  图片2: 集合点位置图（有标注）- 高度相关 ✅
  图片3: 疏散方向示意图 - 相关 ✅
  
评分结果: 预期提升到 12-14/15 (80-93%)
优势: 所有图片都包含疏散路线、集合点、方向标注等关键信息
```

## 关键特性

### 1. 智能排除
- ✅ 自动排除空白页
- ✅ 自动排除纯文本页（无图表）
- ✅ 优先选择有标注的地图类图片

### 2. 多维度评分
- OCR文本关键词匹配
- 视觉特征检测
- 页码位置信息
- 特殊模式识别

### 3. 针对性策略
每个评分项都有专门的选择逻辑，确保选中的图片最适合该评分项的要求。

## 配置示例

在比赛评分配置中，每个评分项都定义了 `image_keywords`：

```python
"evacuation_route_annotation": {
    "image_keywords": [
        "逃生路线", "疏散路线",
        "集结点", "集合点",
        "疏散方向", "标注",
        "影响半径"
    ],
    "check_items": [
        "逃生路线标注及文字说明",
        "应急疏散集结点位置标注及文字说明",
        "疏散方向合理性：应向管道两侧",
        "集结点位置合理性：应在潜在影响半径范围以外"
    ]
}
```

智能选择器会：
1. 优先选择包含这些关键词的图片
2. 检查图片是否满足 `check_items` 的要求
3. 排除明显不相关的图片

## 后续优化方向

1. **更精确的视觉特征检测**

2. **语义理解**

3. **动态调整**

   - 学习哪些图片类型评分效果好
