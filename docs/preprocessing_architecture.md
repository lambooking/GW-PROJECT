# 数据预处理架构文档

## 概述

本文档详细描述了竞赛文档分析与评分系统的数据预处理架构。该架构设计旨在满足技术规格书中提出的多模态文档处理、场景自动识别、实体提取与关联等核心需求，同时确保系统在120秒的时间限制内完成高质量的文档预处理。

## 核心模块详解

### 1. DocumentParser 基础文档解析器

**职责**: 提供基础的文档解析能力，支持DOCX和PDF格式

**功能特性**:
- DOCX文档解析：段落、表格、图片提取
- PDF文档解析：文本、图片提取
- OCR文字识别：图片内容识别
- 文档分类：自动识别场景类型

**技术实现**:
- 使用`python-docx`库解析Word文档
- 使用`PyMuPDF`库解析PDF文档
- 使用`PaddleOCR`进行中文OCR识别
- 集成文档分类器实现自动场景识别

### 2. EnhancedPDFParser 增强PDF解析器

**职责**: 提供增强的PDF解析能力，特别针对表格提取

**功能特性**:
- 高精度表格提取：使用`pdfplumber`库
- 文本结构化：章节识别、层级分析
- 表格内容清理：格式标准化、去重处理
- 文本模式表格识别：基于制表符和空格的表格识别

**技术实现**:
- 双引擎解析：`PyMuPDF` + `pdfplumber`
- 表格有效性验证：内容密度检查
- 文本表格识别：正则表达式模式匹配
- 结果去重和优化

### 3. DocumentClassifier 文档分类器

**职责**: 自动识别文档属于场景一还是场景二

**功能特性**:
- 关键词匹配：基于预定义关键词库
- 结构特征分析：文档结构模式识别
- 置信度评估：分类结果可信度量化
- 多维度评分：关键词+结构综合评分

**分类逻辑**:
```python
# 场景一关键词：作业指导书、操作规程、巡检、应急预案等
# 场景二关键词：高后果区、风险管控、HCA、风险评价等
# 结构特征：章节编号模式、特定表格类型等
总分 = 关键词匹配分数 + 结构特征分数
置信度 = 最高分 / (最高分 + 次高分)
```

### 4. StructuredDataExtractor 结构化数据提取器

**职责**: 将解析后的原始内容转换为结构化数据

**功能特性**:
- 基础信息提取：标题、编号、版本、页数
- 结构信息分析：章节层次、目录完整性、附录关联
- 技术参数提取：压力、温度、直径等参数识别和标准化
- 人员信息提取：姓名、职务、联系方式
- 标准信息提取：标准编号识别和分类
- 日期信息提取：各类时间信息及语义标注

**核心算法**:
- 正则表达式模式匹配
- 上下文语义分析
- 单位标准化和数值验证
- 实体关系抽取

### 5. MultimodalFusion 多模态融合器

**职责**: 整合文本、表格、图片信息，建立跨模态关联

**功能特性**:
- 内容分类组织：按类型和主题对内容进行分类
- 跨模态关联：建立文本-表格、文本-图片、表格-图片关联
- 语义相似度计算：基于内容相似性建立关联
- 场景特定融合：针对不同场景的特定融合逻辑

**关联算法**:
```python
# 语义相似度计算
def calculate_similarity(type1, type2):
    if direct_match(type1, type2):
        return 1.0
    elif keyword_overlap(type1, type2):
        return overlap_ratio
    else:
        return 0.0

# 关联阈值
text_table_threshold = 0.7
text_image_threshold = 0.6
table_image_threshold = 0.6
```

### 6. EntityExtractor 实体提取与标注器

**职责**: 精确提取和标注文档中的关键实体

**功能特性**:
- 日期实体提取：多种日期格式识别，语义类型标注
- 人员实体提取：中文姓名识别，职务关联，联系方式提取
- 技术参数实体：数值提取，单位标准化，有效性验证
- 地理位置实体：里程标记，坐标信息，行政区划
- 标准编号实体：国标、行标、国际标准识别
- 组织机构实体：公司、部门、职位识别

**实体验证**:
- 日期逻辑验证：编制时间 > 风险评价时间 > 识别时间
- 技术参数验证：数值范围合理性检查
- 人员信息验证：姓名-职务-联系方式一致性
- 地理信息验证：坐标格式和行政区划匹配

### 7. PreprocessingPipeline 综合预处理管道

**职责**: 协调所有模块，提供完整的预处理流程

**处理流程**:
1. **文档解析与分类** (≤10秒)
2. **结构化数据提取** (≤15秒)
3. **多模态融合** (≤10秒)
4. **实体提取与标注** (≤20秒)
5. **OCR处理** (≤15秒，可选)
6. **质量评估与输出** (≤5秒)

**性能优化**:
- 并行处理：图片OCR与文本处理并行
- 缓存机制：重复内容识别和缓存
- 早停机制：低质量文档提前终止
- 资源监控：内存和CPU使用率监控

## 质量保证

### 质量评估指标
1. **解析质量** (25%): 文本、表格、图片提取完整性
2. **结构质量** (25%): 章节识别、目录完整性、层次清晰度
3. **融合质量** (25%): 跨模态关联合理性、内容组织度
4. **实体质量** (25%): 实体识别准确性、关系抽取正确性

### 质量等级定义
- **A级 (90-100%)**: 优秀，可直接用于分析
- **B级 (80-89%)**: 良好，轻微缺陷不影响分析
- **C级 (70-79%)**: 合格，需要人工验证部分内容
- **D级 (60-69%)**: 较差，需要大量人工干预
- **F级 (<60%)**: 失败，无法用于分析

### 错误处理策略
1. **格式错误**: 返回详细错误信息，建议格式修正
2. **内容缺失**: 记录警告，继续处理可用部分
3. **解析失败**: 尝试备用方法，记录失败原因
4. **超时处理**: 保存已处理部分，标记未完成状态
