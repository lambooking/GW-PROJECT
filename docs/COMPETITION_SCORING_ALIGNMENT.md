# 比赛评分细则对齐方案

## 背景说明

比赛方对我们输出的报告有明确的评分标准，我们需要调整RAG评分引擎的配置，使输出的报告能够满足这些评分要求，获得高分。

## 比赛方评分细则分析

### 场景一：作业指导书审核

#### 当前比赛方评分维度：

1. **整体审核** - 内容与结构完整性
   - 作业区概况、QHSE目标指标、岗位设置与职责
   - 重点作业流程及内容、操作指南、应急处置等
   
2. **细节审核**
   - **文字及语法错误** - 句子通顺、标点符号正确、专业术语准确
   - **业务逻辑错误** - 上下逻辑连贯、时间与文字表述对应
   - **应急处置审核** - 针对生产异常事件处置流程、处置顺序、缺失关键步骤
   
3. **识别效率** - 按档次评分（60秒以内、60-120秒、120-180秒、180-240秒、>240秒）

4. **兼容性评价** - 需兼容WORD和PDF格式 ✅

5. **模板检测** - 识别是否使用规定模板

### 场景二：高后果区风险管控方案审核

#### 当前比赛方评分维度：

**核心能力要求（多模态理解）：**

1. **签字页手签识别** (权重参考: 10%)
   - 识别签字页手签痕迹

2. **内容完整性** (权重参考: 15%)
   - 人员密集型：高后果区影像图、现场图、入场线路图、逃生路线图及应急疏散集合点位置
   - 环境敏感型：高后果区影像图、现场图、入场线路图、水体敏感型高后果区围油设施放置图

3. **影像图标注识别** (权重参考: 15%)
   - 影像图管道位置（实线）及潜在影响半径（虚线）线条
   - 管道周边的各类入口的建筑物和环境受体的名称和相关信息

4. **入场线路图标注识别** (权重参考: 15%)
   - 入场路线标注及文字说明
   - 入场路线是否合理（路线不能穿山、穿墙、无桥跨河、穿建筑物、不在可行车道路）

5. **逃生路线图、应急疏散集结点标注识别（人员密集型）** (权重参考: 15%)
   - 逃生路线、应急疏散集结点位置标注及文字说明
   - 路线和位置是否合理（疏散方向标注应向管道两侧，集结点位置应在潜在影响半径范围以外）

6. **图片标注一致性** (权重参考: 5%)
   - 高后果区特征描述部分对建筑物描述与影像图标注是否一致

7. **上下文内容一致性** (权重参考: 10%)
   - 人防措施中涉及的区段长信息与高后果区基本信息表是否一致
   - 位置信息与高后果区风险评价结果表是否一致

8. **标准遵从度** (权重参考: 5%)
   - 是否参照GB32167（高后果区识别标准）相关规定

9. **内容完整性** (权重参考: 5%)
   - 文中若存在人员密集型高后果区的表则应包含市政管网交叉位置图
   - 文中若存在输油管道环境敏感类高后果区描述则应包含水体敏感型高后果区围油设施放置图

10. **时间逻辑一致性** (权重参考: 5%)
    - 封面编制时间、高后果区识别时间、风险评价时间年份应一致
    - 时间逻辑为"风险评价时间晚于识别时间"

11. **数据逻辑是否正确** (权重参考: 5%)
    - 电位测试结果部分是否超出-0.85V~-1.2V
    - 风险评价结果中可能性、后果值、风险值数据为数值、风险等级为"低、中、较高、高"

12. **文字模板一致性** (权重参考: 5%)
    - 管道本体管控措施、外部环境风险管控、事故状态下前期处置部分描述是否与模板要求一致或包含

## 关键优化点

### 1. 新增评分项

**场景一：**
- 业务逻辑一致性（独立出来）
- 应急处置流程完整性（独立出来，权重加大）
- 模板规范性检测

**场景二：**
- 图片标注一致性检测
- 上下文内容一致性检测
- 标准遵从度（GB32167）
- 时间逻辑一致性
- 数据逻辑正确性
- 文字模板一致性

### 2. 权重调整

根据比赛方的评分细则，重新分配各评分项的权重，使其更符合实际评分标准。

### 3. 评估重点细化

每个评分项都明确了具体的评估重点，与比赛方的要求一一对应。

## 实施计划

1. **第一步**：更新 `rag_scoring_engine.py` 中的评分配置
2. **第二步**：实现新增的评分逻辑（如一致性检测、模板检测等）
3. **第三步**：优化prompt，使AI能够更准确地评估这些维度
4. **第四步**：测试验证，确保输出报告满足比赛方要求

## 注意事项

1. **识别效率**：比赛方对识别时间有要求（第一档≤60秒最佳），这需要在系统性能优化层面解决，不在评分配置中体现

2. **兼容性**：已支持WORD和PDF格式 ✅

3. **模板检测**：需要准备标准模板样本，用于对比检测

4. **多模态理解**：场景二重度依赖图片理解能力，需要确保VLLM模型能够有效分析图片内容

5. **一致性检测**：需要开发专门的逻辑来对比文本内容与图片标注、表格数据的一致性
